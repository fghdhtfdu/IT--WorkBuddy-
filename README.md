多赛道起号的核心能力，其实只有三个
很多人以为三条赛道要学三套完全不同的本事，其实底层能力是相通的。掌握了核心能力，赛道只是表现形式的不同。

能力一：选题与需求洞察

无论是自媒体文章、口播脚本还是智能体功能，第一步都是找到"别人真正关心的问题"。训练营会反复训练这种敏感度：从评论区找痛点，从热搜找趋势，从自己的日常困扰找切口。一个好选题，等于成功了一半。选题能力可以迁移到任何赛道。

能力二：内容与产品的结构化表达

自媒体要结构清晰，口播要逻辑顺滑，智能体要流程明确。它们的共同点，都是把复杂的东西拆成用户能轻松接受的步骤。课程中会训练"开头抓人、中间给价值、结尾引导行动"的通用框架，这套框架在三条赛道里都能用。

能力三：持续迭代与数据复盘

起号初期，数据不会骗人。哪条内容互动高、哪个功能被反复使用、哪句话让用户停留更久，都是迭代的依据。训练营强调用数据说话，而不是凭感觉判断。会复盘的人，起号速度往往快得多。

三个能力，一个心法

选题解决"做什么"，表达解决"怎么做"，复盘解决"怎么做得更好"。这三样练扎实了，你在自媒体、口播、智能体之间切换，成本会低很多。真正的门槛不在赛道，而在这些可迁移的底层能力
